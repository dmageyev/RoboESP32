# Специфікація проекту: Робомашинка на ESP32 з WEB-інтерфейсом

## 1. Огляд

Цей документ описує вимоги до проекту робомашинки на базі мікроконтролера ESP32 з можливістю керування через веб-інтерфейс.

## 2. Апаратне забезпечення

### 2.1. Основні компоненти

*   **Мікроконтролер:** ESP32
*   **Драйвер двигунів:** DRV8833

### 2.2. Керування рухом

*   **Двигуни:** Два двигуни постійного струму.
*   **Керування:**
    *   Керування швидкістю (ШІМ).
    *   Керування напрямком руху (вперед, назад, вліво, вправо).
    *   Можливість зупинки.
*   **Балансування:** Можливість налаштування коефіцієнтів для балансування швидкості лівого та правого двигунів.

### 2.3. Світлові та звукові сигнали

*   **Фари:** Увімкнення/вимкнення передніх фар.
*   **Габаритні вогні:** Увімкнення/вимкнення габаритних вогнів.
*   **Стоп-сигнал:** Автоматичне увімкнення при гальмуванні або зупинці.
*   **Сигнали поворотів:** Окреме увімкнення/вимкнення лівого та правого поворотів.
*   **Сигнал заднього ходу:** Автоматичне увімкнення при русі назад.
*   **Гудок:** Можливість увімкнути звуковий сигнал.

### 2.4. Призначення пінів та з'єднання

| Пін ESP32 | Призначення                | Компонент                |
| --------- | -------------------------- | ------------------------ |
| GPIO 23   | `AIN1` Лівий двигун        | DRV8833                  |
| GPIO 22   | `AIN2` Лівий двигун        | DRV8833                  |
| GPIO 21   | `BIN1` Правий двигун       | DRV8833                  |
| GPIO 19   | `BIN2` Правий двигун       | DRV8833                  |
| GPIO 18   | Фари                       | Світлодіод(и)            |
| GPIO 5    | Габаритні вогні            | Світлодіод(и)            |
| GPIO 17   | Стоп-сигнал                | Світлодіод(и)            |
| GPIO 16   | Лівий поворот              | Світлодіод(и)            |
| GPIO 4    | Правий поворот             | Світлодіод(и)            |
| GPIO 2    | Сигнал заднього ходу       | Світлодіод(и)            |
| GPIO 25   | Гудок (ЦАП)                | П'єзодинамік/динамік     |
| 3.3V      | VCC                        | DRV8833, інші компоненти |
| GND       | GND                        | DRV8833, інші компоненти |

**Примітка:** Для керування швидкістю двигунів за допомогою ШІМ (PWM), необхідно буде використовувати відповідні функції ESP32 (LEDC). Для гудка використовується пін з ЦАП (GPIO 25) для генерації аналогового звукового сигналу.

## 3. Програмне забезпечення

### 3.1. Мікроконтролер (ESP32)

*   **Прошивка:** Написана на C++ з використанням Arduino Core.
*   **WiFi:** ESP32 працює в режимі точки доступу (Access Point) або підключається до існуючої WiFi мережі.
*   **Веб-сервер:** Вбудований веб-сервер для надання веб-інтерфейсу.
*   **API:** WebSocket або HTTP API для обміну даними між веб-інтерфейсом та мікроконтролером в реальному часі.

### 3.2. Веб-інтерфейс

*   **Технології:** HTML, CSS, JavaScript.
*   **Елементи керування:**
    *   Джойстик або кнопки для керування напрямком та швидкістю руху.
    *   Кнопки для увімкнення/вимкнення фар, габаритів, та гудка.
    *   Індикатори стану (наприклад, стан підключення, увімкнені фари).
    *   Можливість виводу діагностичної інформації від машинки.
*   **Адаптивність:** Інтерфейс має бути адаптованим для використання на мобільних пристроях та настільних комп'''ютерах.

## 4. Функціональні вимоги

*   Пристрій створює точку доступу Wi-Fi, до якої можна підключитися.
*   Після підключення до точки доступу, користувач може відкрити веб-інтерфейс, ввівши IP-адресу ESP32 у браузері.
*   Веб-інтерфейс дозволяє керувати рухом машинки, а також її світловими та звуковими сигналами.
*   Зворотній зв'''язок від машинки (наприклад, дані з сенсорів) може відображатися в веб-інтерфейсі (необов'''язково, для майбутнього розширення).
